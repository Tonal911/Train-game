# Art overrides

Drop image files here to replace the generated art. No code changes needed; restart not required (refresh the page).

| File name | Replaces |
|---|---|
| `card-red.png`, `card-orange.png`, `card-yellow.png`, `card-green.png`, `card-blue.png`, `card-purple.png`, `card-black.png`, `card-white.png` | the 3D toy wagon art in the middle of each train card |
| `card-loco.png` (or .jpg) | the locomotive (wild) card art (default: `/assets/loco.jpg`) |
| `piece-red.png`, `piece-blue.png`, `piece-green.png`, `piece-yellow.png`, `piece-pink.png` | the toy wagon placed on routes for each player color (top-down view, ~3:1) |
| `cardback.png` | the whole face of the card back |

Transparent PNGs look best for wagons/pieces ("squeezed cutout" style). Images are stretched to fit.
